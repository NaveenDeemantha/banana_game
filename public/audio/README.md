# Background Music

Place your background music file here as `background-music.mp3`.

You can use royalty-free music from:
- https://www.bensound.com/
- https://incompetech.com/
- https://www.purple-planet.com/

Recommended settings:
- Format: MP3
- Bitrate: 128kbps or lower (for smaller file size)
- Loop-friendly (no harsh start/end)
- Upbeat, fun theme matching the banana game aesthetic
